AI Response Evaluation

When evaluating an AI response, I consider factors such as:

Evaluation Area

What I Check

Instruction Following

Whether the response follows the user's request

Accuracy

Whether the information is correct and supported by the task

Relevance

Whether the response stays focused on the requested topic

Completeness

Whether important parts of the instruction are addressed

Clarity

Whether the response is understandable and well organized

Consistency

Whether the response follows the same criteria throughout

Safety and Appropriateness

Whether the response is suitable for the task

Overall Quality

Whether the response effectively serves the user's purpose
