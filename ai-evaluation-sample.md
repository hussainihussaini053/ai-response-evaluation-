# AI Response Evaluation Sample

## Purpose

This sample demonstrates my ability to evaluate AI-generated responses using clear criteria such as accuracy, relevance, instruction following, clarity, and completeness.

## Example Task

**User instruction:**  
Explain photosynthesis to a secondary school student using simple English.

### AI Response A

Photosynthesis is the process by which green plants make their own food. Plants use sunlight, water, and carbon dioxide to produce food and release oxygen. This process mainly takes place in the leaves.

### AI Response B

Photosynthesis is a complex biochemical mechanism in which photoautotrophic organisms convert radiant solar energy into chemical energy through a series of photochemical and biochemical reactions.

## Evaluation

| Criterion | Response A | Response B |
|---|---|---|
| Accuracy | Meets | Meets |
| Relevance | Meets | Meets |
| Instruction Following | Meets | Needs improvement |
| Clarity | Meets | Needs improvement |
| Completeness | Meets | Meets |

## Human Feedback

Response A better follows the user's instruction because the user specifically requested a simple explanation for a secondary school student. It is accurate, clear, and easy to understand.

Response B contains scientifically relevant information, but it uses advanced terminology and is less suitable for the intended audience. The response could be improved by using simpler language and explaining technical terms.

## Evaluation Skills Demonstrated

- Instruction following
- Accuracy checking
- Relevance assessment
- Clarity assessment
- Comparative evaluation
- Human feedback
- Critical thinking
- Attention to detail

## Conclusion

This sample demonstrates a structured approach to evaluating AI-generated responses. The goal is not only to identify whether an answer is correct, but also to determine whether it satisfies the user's specific instructions and communication needs.
